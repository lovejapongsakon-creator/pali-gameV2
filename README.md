เกมการเรียนรู้สำหรับรายวิชาภาษาบาลี บ21202 ชั้นมัธยมศึกษาปีที่ ๑
โรงเรียนพระปริยัติธรรมวัดธรรมมงคล แผนกสามัญศึกษา · ครูผู้สอน: พระมหาพงศกร กิตฺติวํโส

- **หน้าเว็บ** อยู่บน GitHub Pages (ฟรี เร็ว ไม่ล่ม)
- **ฐานข้อมูล** คือ Google Sheet ของครู (รายชื่อ, ตารางเปิดหน่วย, ข้อสอบเพิ่ม, ผลการเล่น, คะแนน)
- ปีต่อไป **แก้แค่ใน Google Sheet** ไม่ต้องแตะโค้ด

## ขั้นที่ ๑ · ติดตั้งหลังบ้าน (Google Sheet + Apps Script) — ทำครั้งเดียว

1. เปิด Google Sheet ของครู: https://docs.google.com/spreadsheets/d/1xQOsMQQ4xYvnROhgbOTB9-YNW6e6Jz2WQbhVYrht8cw/edit
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ว **วางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs`** → กดบันทึก 💾
4. ด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **▶ เรียกใช้** → อนุญาตสิทธิ์ (ครั้งแรก Google จะถาม ให้กด "ขั้นสูง" → "ไปที่โปรเจกต์")
   ระบบจะสร้างแท็บให้: `Settings` `Units` `Roster` `Questions` `Log` `Progress` `Scores`
5. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ → **คัดลอก URL ที่ลงท้ายด้วย `/exec`**
6. เปิดไฟล์ `js/config.js` แล้ววาง URL ลงใน `API_URL: "..."`

> ถ้าแก้โค้ด Apps Script ภายหลัง ต้องกด Deploy → **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จะคงเดิม

## ขั้นที่ ๒ · ใส่ข้อมูลในชีต

| แท็บ | สิ่งที่ต้องทำ |
|---|---|
| `Roster` | ใส่รายชื่อนักเรียน: `id` (รหัสนักเรียน) · `name` · `class` (เช่น ม.1/1) · `no` |
| `Settings` | `TERM_START` = วันจันทร์ของสัปดาห์ที่ ๑ เช่น `2026-11-02` (ค.ศ.) — แท็บ Units จะคำนวณวันเปิด–ปิดให้ทุกหน่วย |
| `Units` | ปรับวันเปิด–ปิดรายหน่วยได้ · ช่อง `override`: `OPEN` = เปิดตลอด, `CLOSE` = ปิด |
| `Questions` | (ไม่บังคับ) เพิ่มข้อสอบเอง: unit, stage (A1–A5, B1–B5, T หรือเว้นว่าง), คำถาม, ตัวเลือก ๑–๔, answer (๑–๔), explain |

ค่าอื่นใน `Settings`: รหัสครู (`TEACHER_CODE` = 0406), เกณฑ์ผ่าน, จำนวนข้อ, คะแนนเต็ม, จำนวนครั้งที่สอบได้, ข้อความประกาศ
แก้แล้วเกมจะเห็นค่าใหม่ภายใน ๒ นาที (หรือเมนู **หอไตรบาลี → ล้างแคช**)

## ขั้นที่ ๓ · เผยแพร่หน้าเว็บบน GitHub Pages

1. สมัคร/เข้าสู่ระบบ https://github.com → กด **New repository** ตั้งชื่อ เช่น `pali-game` → เลือก **Public** → Create
2. กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (index.html, css, js, assets, manifest.json, sw.js, .nojekyll) → **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. รอ ๑–๒ นาที จะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/pali-game/` → ทำ QR Code แจกนักเรียนได้เลย

> ทุกครั้งที่แก้ไฟล์เกม ให้เปลี่ยนเลข `VERSION` ใน `sw.js` ด้วย เพื่อให้เครื่องนักเรียนโหลดของใหม่

## การใช้งานในห้องเรียน

- **นักเรียน**: เปิดลิงก์ → ใส่รหัสนักเรียน → เล่นหน่วยของสัปดาห์นั้น
- **ครู**: หน้าแรก → "สำหรับครูผู้สอน" → รหัส `0406` → แดชบอร์ด (ดูคะแนนทุกคน กรองตามชั้น ดาวน์โหลด CSV) และ "เปิดดูเกม" ได้ทุกด่านโดยไม่บันทึกผล
- คะแนนเก็บอยู่ในแท็บ **`Scores`** (หน่วยละ ๒ คะแนน รวม ๔๐) ผลละเอียดทุกรอบอยู่ใน **`Log`**
- เน็ตหลุด: เกมเก็บผลไว้ในเครื่องแล้วส่งให้อัตโนมัติเมื่อกลับมาออนไลน์

## ขึ้นปีการศึกษาใหม่

1. `Settings` → เปลี่ยน `YEAR` และ `TERM_START`
2. ย้ายข้อมูลเก่า: คัดลอกแท็บ `Log` `Progress` `Scores` เก็บไว้ (หรือทำสำเนาไฟล์ชีตทั้งไฟล์) แล้วลบแถวข้อมูลออก (เหลือหัวตาราง)
3. ใส่รายชื่อนักเรียนใหม่ใน `Roster`

ถ้าหนังสือเรียนเปลี่ยนเนื้อหา: แก้ไฟล์ `js/data/units.js` หรือเพิ่มข้อสอบผ่านแท็บ `Questions`

## ทดลองในเครื่อง

ถ้า `API_URL` ว่าง เกมจะอยู่ใน **โหมดทดลอง** (เก็บผลในเครื่องเท่านั้น, รหัสครู 0406 ใช้ได้)
เปิดด้วยเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น `python -m http.server` แล้วเข้า http://localhost:8000
